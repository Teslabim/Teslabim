## 🚀 Что такое Teslabim?

**Teslabim** — бесплатный плагин для **Autodesk Revit**, созданный для проектирования внутреннего электрооборудования.

Мы создали Teslabim, потому что устали слышать:

> **«Электрику в Revit сделать невозможно».**

Наш ответ:

> **Возможно. И это можно делать быстрее и качественнее.**

Teslabim объединяет набор инструментов, которые помогают автоматизировать рутинные операции проектировщика и сделать работу с электротехнической моделью Revit удобнее.

Плагин развивается с учётом реальных задач проектирования ЭОМ и предназначен как для отдельных проектировщиков, так и для проектных команд.

---

# ⚡ Возможности

Teslabim помогает автоматизировать различные этапы проектирования электрики непосредственно в Revit.

### 🔌 Электрические сети

- работа с электрическими цепями;
- назначение и обработка цепей;
- работа с номерами цепей;
- расчёт нагрузок;
- сбор нагрузок;
- параметризация элементов;
- расчёт длин кабельных линий;
- создание путей до кабельных трасс;
- визуализация трасс электрических цепей.

### ⚡ Щиты и панели

- создание схем щитов;
- автоматическое формирование схем;
- работа с ВРУ и щитами;
- подбор щитов и панелей;
- информация о НКУ;
- автоматизация заполнения параметров;
- работа с аппаратами защиты;
- расчёт токов короткого замыкания;
- расчёт селективности;
- подбор оборудования.

### 📐 Кабельные трассы

- работа с кабельными лотками;
- работа с кабельными коробами;
- расчёт длин;
- определение способов прокладки;
- построение путей до трассы;
- автоматизация заполнения кабельных трасс.

### 💡 Освещение

- работа с осветительными приборами;
- расчёт и проверка освещённости;
- установка рабочих плоскостей;
- импорт данных из **DIALux**;
- экспорт пространств в DIALux;
- автоматизация обработки светильников.

### 🧩 Семейства Revit

Teslabim включает инструменты для автоматизации работы с семействами:

- пакетная замена параметров;
- обновление семейств по параметрам;
- очистка семейств;
- создание чистых видов в семействах;
- автоматизация работы с параметрами.

Для работы с плагином используется собственный набор семейств **TSL** и шаблон проекта.

### 📊 Спецификации и параметры

- параметризация элементов;
- запись высотных отметок;
- запись количества;
- работа с пространствами;
- автоматическое заполнение параметров;
- экспорт данных в Excel;
- автоматизация формирования спецификаций.

### 🧮 Расчёты

Teslabim позволяет автоматизировать различные инженерные расчёты, в том числе:

- расчёт электрических нагрузок;
- коэффициенты спроса;
- токи короткого замыкания;
- селективность;
- компенсацию реактивной мощности;
- расчёт и обработку электрических цепей.

Для расчётов предусмотрен **редактор формул**, позволяющий создавать собственные формулы и коэффициенты.

### 🔄 Работа со смежными разделами

Teslabim помогает получать данные из связанных моделей Revit.

Например, команда **«Получить задание»** позволяет получать необходимую информацию из связанных файлов и использовать её в текущем проекте.

# 🧠 Почему Teslabim?

Проектирование электрики в Revit может требовать большого количества повторяющихся действий.

Teslabim стремится автоматизировать именно эту рутину.

### Без Teslabim

**Выбрать → настроить → посчитать → заполнить → проверить → повторить**

### С Teslabim

**Запустить команду → получить результат**

Это позволяет проектировщику тратить меньше времени на техническую рутину и больше — на инженерные решения.
